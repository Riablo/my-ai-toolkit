# clipfmt

macOS 剪贴板格式化：成功后将新结果重新复制。原生图片数据可直接粘贴到支持图片的应用；不管理剪贴板历史，不修改源文件。

## 安装与配置

从仓库根目录运行 `bash scripts/install.sh`，或直接执行 `cli/clipfmt/clipfmt`。

依赖：Bash 5+、uv、jq、mmdr、resvg、oxfmt、gdate。Bash 入口使用 uv 执行 Python 辅助程序，首次运行自动安装 PyObjC（原生剪贴板接口）。

在 `~/.config/clipfmt/config.json` 填入自己的密钥（已有配置请保留其他字段）：

```json
{
  "jev_api_key": "你的 TypeSafe API key",
  "deepseek_api_key": "你的 DeepSeek API key"
}
```

```bash
chmod 600 ~/.config/clipfmt/config.json
clipfmt --check  # 验证配置和命令存在性，不读写剪贴板，不请求 API
clipfmt         # 处理当前剪贴板并复制结果
clipfmt -h
```

不自动创建配置、不从示例获取凭据。文本分流需要 Jev key；进入 DeepSeek 分支时才校验 DeepSeek key，缺失或为空则停止，不跳过 AI 步骤。`--check` 检查两项密钥和工具依赖。文件转换不需要 key。密钥不放命令参数，日志不输出密钥、剪贴板正文或子进程错误正文。

## 分流与转换

- Finder 复制的**单个文件**或剪贴板里的**单个绝对路径**：只按后缀分流，不发送 Jev。多个文件、目录和不支持的后缀不处理。支持 UTF-8 / UTF-8 BOM 文件，不下载 URL。
- **所有非空文本**：发送完整文本至 TypeSafe `jev-latest`，由 Choice 选择处理器及代码语言，包含“不支持”。不会先用本地内容规则绕过 Jev。空内容不请求。
- Jev 仅分类，不修改内容、不生成命令。初始 confidence 阈值为 0.8，低于阈值交给 DeepSeek；该阈值是保守初值，尚未经真实样本校准。例外：请求成功后，若本地严格验证文本为“根节点字符串逐层解码后得到 JSON 对象/数组”，则确定选择 JSON 字符串处理器，纠正 Jev 的不支持、低置信度或其他类型判断。不会绕过网络/API 错误。
- 明确匹配本地类型则使用既有工具或确定性脚本；Jev 选择 `ai_format`、未匹配类型或置信度不足时，请求 DeepSeek 整理显示。文件不自动外发。已选择的本地处理器报错仍立即停止，不因超时、缺依赖等错误重新分流。

| 内容 | 行为 |
| --- | --- |
| JSON / `.json` | 单个完整对象或数组，`jq` 两空格缩进；不接受多段 JSON 流 |
| JSON 字符串（文本） | 逐层解开外层 JSON 字符串编码，再用 jq 格式化对象/数组；不转换普通字段中的字符串 |
| URL（文本） | HTTP/HTTPS 地址的百分号编码 Unicode 转为可读字符，保留外围引号及 ASCII 转义 |
| 表格 / `.csv` / `.tsv` | CSV/TSV、多空格分列的疑似表格仅用空格对齐；独立 Markdown 表格保留 Markdown 语法并对齐 |
| 结构化片段（仅文本，由 Jev 选择） | JSON/对象风格的字段片段、带注释和 `0/1` 取值说明的文档，只整理行首缩进 |
| Mermaid / `.mmd` / `.mermaid` | 当前 mmdr 支持的图表转 PNG，使用工具默认尺寸 |
| SVG / `.svg` | `resvg --width 512` 转 PNG；SVG 文件的相对资源按源文件目录解析 |
| 完整且受支持的代码 | `oxfmt`，使用独立临时目录和显式空配置，不读取所在项目的格式化配置 |
| 通用缩进（文本） | 不限代码语言或语法完整性；Bash、Python、Rust、配置/普通缩进块等只去除公共外层缩进，不执行内容 |
| 时间 | 10 位秒 / 13 位毫秒 Unix 时间戳，或带明确四位年份且 `gdate -d` 能解析的绝对日期 |
| 其余/不确定/错乱折行的文本 | DeepSeek `deepseek-flash`，`thinking.type=disabled`，调整空白、换行和缩进；允许受校验约束的 JSON 闭合括号补全 |

首版代码白名单：JS/JSX/TS/TSX（含 mjs/cjs/mts/cts）、JSONC/JSON5、YAML（含 yml）、TOML、HTML、Vue、Svelte、CSS/SCSS/Less、GraphQL（含 gql）、MDX。Python、Bash、Rust 等文本虽无专用语法格式化器，仍可通过通用缩进处理；文件后缀白名单不因此扩大。

支持单个完整 Markdown 代码围栏，输出去掉围栏。完整且受支持的代码由格式化器处理；残缺代码或其他缩进块可由 Jev 选择 `indent`，仅去掉公共外层缩进，不要求语法合法，也不补内容。已经选定的格式化器报错仍会停止，不在失败后偷偷改用另一处理器。

通用缩进只删除所有非空行共有的空格/制表符前缀，保留行内文字、内部相对缩进和换行，不执行任何复制的命令。已顶格的 `def f():` 下方函数体不会被整体左移。对 `/bin/bash <<'BASH'` 这类首行顶格的单 heredoc 包装，如果末尾结束标记和所有正文行共享额外缩进，则以结束标记的缩进为依据删除正文公共前缀，让结束标记正确顶格；缺失或不一致时不猜。不能恢复任意被打乱的内部层级；无法区分首行丢失缩进与合法嵌套时保守保持原样。

结构化片段使用本地扫描器按 `{}` / `[]` 嵌套层级整理为两空格缩进，不修改行内内容、不拆行、不补括号，保留 `0/1`、尾逗号及注释。识别单/双引号字符串、转义、`#` / `//` 行注释和 `/* */` 块注释，其中的括号不参与层级计算；块注释的后续行保持原样。选区可以没有最外层对象，但选区内部的括号必须匹配且闭合；未闭合注释、跨行字符串、模板字符串或无法判断的斜杠表达式会停止，不改剪贴板。

例如，复制 `"config": { ... },` 这样的多行字段片段，即使含 `"enabled": 0/1, # 是否开启`，也可只整理缩进。完整合法 JSON 仍走 jq。对于文本，即使 Jev 将 `"data": {...},` 这类字段选区判为 JSON/JSONC/JSON5，本地也会在调用严格解析器前识别带引号键名的属性片段，直接整理缩进，不要求补上最外层 `{}`，也不依赖 Jev 必须准确选择 fragment。这不是工具报错后的重试；真正的工具错误仍立即停止。文件仍按后缀分流，不会在 `.json` 解析失败后自动切换到片段处理器。

URL 只解码非 ASCII Unicode（例如 `%E4%B8%AD` → `中`），不解码 `%2F`、`%26`、`%20`、`%25` 等 ASCII 转义，不把 `+` 改成空格，也不递归解码。这样不会把编码的数据变成路径/查询分隔符。非法 UTF-8、错误百分号编码或不可安全显示的 Unicode 控制/分隔字符会停止。不访问该 URL。

JSON 字符串例如 `"{\"name\":\"foo\",\"data\":{\"id\":1}}"` 会展开成完整格式化 JSON。只解除根节点的字符串编码（最多 16 次解析），保留对象内本来就是字符串的字段；不能展开为对象/数组时停止。正文即使含长篇中英文或 `\\n` 转义也不影响外层类型；本地校验不改变字段里的字符串内容，不把普通散文、普通字符串或对象中的字符串字段强行转成对象。

表格用 Python 标准库 `csv` 解析逗号、制表符或分号分隔的数据，第一行作为表头，至少两列和一行数据，所有行列数须一致。只有 Markdown 输入保留竖线、分隔行和左右对齐标记。CSV/TSV 输出列间至少两空格的纯文本，不添加竖线或分隔行，最后一列不补齐空格，单元格里的反斜杠和竖线原样保留。拒绝跨行单元格和控制字符，不猜测普通散文、单空格分隔文本或混合文档的列。

从 HTML 页面复制出来的疑似表格也可由 Jev 选择表格处理器：未识别为 CSV/TSV 时，尝试按连续两个以上空白字符（含不换行空格 NBSP）或制表符分列，保留单元格内部的单个空格。仍要求至少两列、表头和数据行列数一致；有空白中间行、列数不一致或无法识别的引号时停止，不补缺失单元格。这里只处理剪贴板文本，不解析 HTML DOM；若复制时列边界已丢失，不能保证恢复。合法 CSV 解析失败不会切换此规则来修补。

列宽按常见中文宽字符和组合音标估算，无额外依赖；**需要等宽字体**，复杂 Emoji/不同字体的显示宽度不保证一致。文件仍只按后缀分流：`.csv` / `.tsv` 支持，`.md` 文件暂不支持，但复制独立 Markdown 表格文本可以识别。

CSV/TSV 输出示例：

```text
a  b      c
1  hello  test
```

Markdown 输出示例：

```text
| a   | b     | c    |
| --- | ----- | ---- |
| 1   | hello | test |
```

日期输出为 `YYYY-MM-DD HH:mm:ss`，遵循本机时区（或环境变量 `TZ`）。毫秒先整除 1000。带时区输入转换成本地时间；无时区输入按本地时间解释；只有日期则为零点。不处理相对日期或让 AI 改写日期。纯数字无法绝对区分时间戳和业务编号，仍依赖 Jev 判断。

## DeepSeek 格式整理

固定请求官方 `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`，显式 `thinking: {"type":"disabled"}`，非流式，温度 0，最多输出 8192 tokens。输入作为数据，不提供工具、不执行指令，要求只返回整理后的原文，不加解释或新的代码围栏。

本地必须确认：响应正常结束（`finish_reason=stop`）、非空、响应不超过 1 MiB。默认要求**去除所有空白后，输入输出字符序列完全相同**。

唯一的非空白变更例外：原文以 `{` 或 `[` 开头时，允许补充匹配已有开括号的 JSON 闭合符 `}` / `]`，且补全后必须通过严格 JSON 对象/数组解析。括号位置由本地扫描器确定，不交给模型猜：忽略字符串中的括号，只在原有闭合符类型不匹配处或文本末尾补上必要的闭合符；不接受在任意逗号处提前闭合而改变字段所属层级。

如果去空白的候选结构能通过严格 JSON 校验，先将确定的闭合符补到原始文本（保留原来的空白和字符串空格），再发送 DeepSeek 整理折行。模型返回后，再按同一确定结构校验/补全；只有非空白序列完全符合预期且结果是合法 JSON 才接受。模型漏补括号不会再导致保留压缩的非法 JSON；若模型移动了层级、改写内容或未修复字符串内的非法折行，仍拒绝。改变文字/数值、补引号/逗号/字段、增加开括号、删除原括号、修复非 JSON 代码或输出截断都拒绝，不写剪贴板。若没有可安全整理之处，模型应返回原文。

通过上述 AI 输出校验后，若结果本身是合法 JSON 对象或数组，再调用 `jq --indent 2 .` 展开排版。不会再次请求 Jev，不展开 JSON 字符串，也不额外猜补结构；不是合法 JSON 时直接保留 AI 整理结果。jq 执行失败则停止，不写剪贴板；最终结果与原文相同才跳过复制。

结构探测中去空白的版本只用于校验，绝不直接作为输出，避免把正常的 `hello world` 改成 `helloworld`。此检查能限制内容改写，**不能保证空白语义完全不变**：例如字符串里的空格、Python 缩进、段落分隔和 `1 2` 与 `12` 的区别，需要使用者检查。括号补全也不能证明恢复了作者原始意图；这里只允许上述有限的 JSON 闭合符插入，不恢复丢失文字。没有补全且只改空白的结果仍可能不是合法 JSON。

## 安全与失败行为

- **文本会离开电脑发送到 TypeSafe；未匹配、不确定或 AI 整理分支还会发送完整文本到 DeepSeek**。普通文本现在也可能进入该分支，不允许外发的内容不要使用。密钥仅发送至各自固定官方端点。
- 输入最多 128 KiB，超过就停止，不截断后发送。每个 API 请求或工具执行超时 30 秒，无自动重试。
- 结果与原文相同：成功退出，不写剪贴板。DeepSeek 分支成功会提示 `已复制：ai_format`。不支持的文件仍直接忽略，不调用模型。
- 配置、网络、解析、工具、文件等失败：非零退出，停止，不尝试其他处理器。
- 全部转换与图片解码成功才写剪贴板；通过 changeCount 检查期间是否发生新的复制，有变化就取消。
- 原生剪贴板 API 没有原子 compare-and-swap，检查与写入之间仍有极小竞态窗口。写入阶段失败尽力恢复所有原始数据类型，不能保证系统级事务性恢复。
- PNG 存放于权限隔离的 `/tmp/clipfmt-*/image.png`，成功后保留并打印路径。失败产物清理；长期敏感图片可自行清理。不会复制文件路径冒充图片。
- SVG 文件可以引用本地资源；只处理可信文件。源文件始终只读。

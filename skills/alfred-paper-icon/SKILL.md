# Alfred Paper Icon

延续用户选定的 `04-layered-paper` 风格。统一纸片的造型语言，颜色随主题变化；参考图中的青绿、暖白和珊瑚橙只是示例，不是固定色板。

## 风格约定

- **形体**：正面、近似正交视角；圆润、精确裁切的卡纸形状，通常由 2–3 个主要薄层叠放。保留轻微厚度，避免变成鼓胀的黏土或厚塑料。
- **光照**：柔和光线来自左上方；层与层之间有窄而浅的接触阴影。表面哑光、以大色块为主，允许随纸片受光产生轻微明暗。
- **细节**：纸面干净，只保留克制的材质感；不用明显纸纹、褶皱、粗描边、镜面高光或夸张渐变。参考图边缘的杂色和毛边不属于风格，应避免复现。
- **构图**：一个清晰主体，按需要搭配一个辅助符号；圆角、粗短细节、均衡留白。主体最长边以画布的约 75%–85% 为起点，按视觉重量调整，不裁切轮廓。
- **配色**：按功能语义、对象本色、品牌或用户偏好自主选色，可丰富多彩。保持主次与相邻纸片的明度差，不把整套图标锁定为同一主色或固定数量的颜色。
- **成品**：正方形、单个独立图标、真实透明背景。默认无文字、数字、场景或底板；用户明确要求时再加入必要内容。

传给生图工具时，明确图片只用于参考材质、薄层厚度、圆角、光照和细节密度；新图的主题与颜色由本次请求决定。不要复制示例物体、配色或边缘瑕疵。

## 生成

1. 从 Workflow 功能提炼易辨认的视觉符号。功能已清楚时直接决定构图和配色；只有缺少核心用途才询问，不为颜色选择反复确认。默认生成一张，数量以用户要求为准。
2. 使用可用的 `imagegen` skill 和内置生图工具生成位图；将选中的本地参考图作为实际图片输入。遵循其生成与保存流程，不为了尺寸、透明背景或普通质量问题擅自切换到收费 API。
3. 提示词由本次主题、配色、上面的风格约定和参考图角色组成。明确要求真实透明 alpha，避免画出棋盘格。正方形可先请求 1024 × 1024；最终尺寸以文件检查为准，不把请求尺寸当成实际结果。
4. 若带参考图的输出反复把透明棋盘格画进背景，保留已经提炼的风格与配色文字，尝试不附图的新生成。此时如实记录未使用图片输入，不宣称使用了参考图。

## 验收与保存

查看生成图，与所选参考图比较薄层厚度、圆角、光照和复杂度；颜色变化本身不算风格偏离。关注图标缩至 32 / 64 像素时的识别度，以及浅色、深色背景下的轮廓。检查主体有没有被错误挖空、阴影有没有变成脏斑、边缘有没有明显白边或彩边。

用只读脚本检查 PNG 格式、正方形尺寸和透明通道：

```bash
uv run "<skill-dir>/scripts/check_icon.py" "/path/to/icon.png"
```

脚本可接收多个文件。通过只代表这些文件属性符合要求，不能替代目视检查；有 alpha 通道仍可能存在棋盘格残留或主体内部的透明破洞。

对发现的问题定向修改或重新生成。同一问题最多重试两次；仍不合格时保存为草稿并说明具体缺陷，不作为正式图标交付。

按用户指定位置保存；未指定时，已有明确 Workflow 项目就放到其图标资源位置，否则放到 `~/Downloads/alfred-paper-icons/<主题>/`。复制生成原图并保留工具原件；未要求替换时使用新文件名。图片旁保存实际使用的 `.prompt.txt`，记录选用的参考图、配色和实际尺寸。交付图片路径及简短检查结果。
